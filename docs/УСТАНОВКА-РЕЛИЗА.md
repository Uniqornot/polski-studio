# Polski Studio 1.0.0 — установка готового контейнера

Образ для Linux x86-64 (linux/amd64). На Windows нужен Docker Desktop с Linux-контейнерами. На ARM этот выпуск потребует эмуляции либо сборки из исходников.

## Файлы выпуска

- `polski-studio-1.0.0-docker-linux-amd64.tar.gz` — готовый Docker-образ.
- `polski-studio-1.0.0-install.zip` — Compose, пример настроек и эта инструкция.
- `polski-studio-1.0.0-source.zip` — исходный код и скриншоты.
- `SHA256SUMS.txt` — контрольные суммы.

## Установка без сборки

Скачайте архив образа и архив установки со страницы релиза:
https://github.com/Uniqornot/polski-studio/releases/tag/v1.0.0

Распакуйте архив установки, положите архив образа в тот же каталог и откройте терминал в этом каталоге.

```bash
docker load -i polski-studio-1.0.0-docker-linux-amd64.tar.gz
mkdir -p cache output
docker compose up -d
```

На Windows PowerShell вместо `mkdir -p cache output`:

```powershell
New-Item -ItemType Directory -Force cache, output
```

Откройте http://127.0.0.1:8080. API-ключ не нужен; для синтеза нужен интернет. Образ уже содержит Python, ffmpeg, шрифты и зависимости.

На Linux при UID вашего пользователя, отличном от 1000, предоставьте контейнеру права записи:

```bash
sudo chown -R 1000:1000 cache output
```

## Проверка и остановка

```bash
docker compose ps
docker compose logs --tail=100 studio
docker compose down
```

Ожидается статус `healthy`. Остановка не удаляет каталоги `cache` и `output`. Ресурсы ограничены: 2 CPU, 1 ГиБ RAM, 128 процессов. Квоты на диск нет.

## Настройки

Скопируйте `.env.example` в `.env`. Для доступа из LAN укажите IP компьютера в `TTS_BIND_ADDRESS`, порт — в `TTS_PORT`. При обратном прокси задайте `TTS_ALLOWED_ORIGINS=https://ваш-домен`. После изменения выполните `docker compose up -d`.

Авторизации в приложении нет. Публичный доступ защищайте на прокси. Настройте правовую информацию и контакт под свой сервис перед самостоятельной публикацией.

## Использование

Вставьте пары «польская фраза - русский перевод», нажмите «Очистить и проверить». При отсутствии ошибок кнопка «Создать видео» станет зелёной. Готовые MP3 и MP4 скачиваются из интерфейса. Изменение текста требует повторной проверки.

Каждый скачанный файл удаляется с сервера через 10 минут после первого полного скачивания. После первого скачивания любого результата отчёт, исходный текст и связанный речевой кэш также очищаются через 10 минут; активная генерация задерживает удаление кэша. Нескачанные результаты и малые технические записи остаются до явной очистки. Подробности — в README репозитория.

## Контрольные суммы

Linux:

```bash
sha256sum -c SHA256SUMS.txt
```

В PowerShell сверяйте `Get-FileHash <имя-файла> -Algorithm SHA256` с `SHA256SUMS.txt`. Для проверки всех сумм скачайте все три соответствующих архива.
